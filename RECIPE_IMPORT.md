# Инструкция по заполнению JSON-файла рецепта

Скачай шаблон: `твой-сайт.com/recipe-template.json`
Заполни его в любом текстовом редакторе, загрузи через кнопку **📥 Импорт JSON** в админке.

---

## Структура файла

```json
{
  "title": "Борщ украинский",
  "description": "Наваристый борщ с говядиной и свёклой.",
  "prepTime": 20,
  "cookTime": 90,
  "difficulty": "medium",
  "isOriginal": false,
  "published": false,
  "tags": ["govyadina", "sup", "ukrainskaya", "deshevoe"],
  "ingredients": [...],
  "steps": [...]
}
```

---

## Поля

| Поле | Тип | Описание |
|------|-----|----------|
| `title` | строка | Название рецепта |
| `description` | строка | Краткое описание блюда |
| `prepTime` | число | Время подготовки в **минутах** (0 если не нужно) |
| `cookTime` | число | Время приготовления в **минутах** |
| `difficulty` | строка | Сложность: `easy`, `medium` или `hard` |
| `isOriginal` | true/false | Авторский рецепт? |
| `published` | true/false | Опубликовать сразу? Обычно `false` — проверишь сначала |
| `tags` | массив slug | Теги из списка ниже |
| `ingredients` | массив | Список ингредиентов |
| `steps` | массив | Шаги и разделители |

---

## Ингредиенты

Каждый ингредиент — объект с тремя полями:

```json
"ingredients": [
  { "name": "Говядина", "amount": "500", "unit": "г" },
  { "name": "Свёкла", "amount": "2", "unit": "шт" },
  { "name": "Капуста", "amount": "300", "unit": "г" },
  { "name": "Соль", "amount": "", "unit": "по вкусу" }
]
```

Популярные единицы: `г`, `кг`, `мл`, `л`, `шт`, `ст.л.`, `ч.л.`, `стакан`, `зубчик`, `пучок`, `по вкусу`

## Шаги и разделители

Шаги бывают двух видов: **обычный шаг** и **разделитель** (заголовок этапа).

### Обычный шаг
```json
{ "text": "Нарезать свёклу тонкой соломкой." }
```
Поле `type` можно не указывать — по умолчанию это шаг.

Жирный текст: обернуть слова в `**двойные звёздочки**`:
```json
{ "text": "Варить **40 минут** на медленном огне." }
```

### Разделитель (заголовок этапа)
```json
{ "type": "divider", "label": "Подготовка", "emoji": "🔪" }
```
- `type` — обязательно `"divider"`
- `label` — название этапа (произвольный текст)
- `emoji` — любой эмодзи

### Пример полного раздела steps
```json
"steps": [
  { "type": "divider", "label": "Подготовка", "emoji": "🔪" },
  { "text": "Нарезать свёклу тонкой соломкой." },
  { "text": "Нашинковать капусту." },
  { "text": "Картофель нарезать кубиком." },

  { "type": "divider", "label": "Варка", "emoji": "🥘" },
  { "text": "Залить говядину холодной водой, довести до кипения, снять пену." },
  { "text": "Варить **1.5 часа** на медленном огне." },
  { "text": "Добавить свёклу и картофель, варить 20 минут." },
  { "text": "Добавить капусту, варить ещё 10 минут." },

  { "type": "divider", "label": "Подача", "emoji": "🍽️" },
  { "text": "Разлить по тарелкам, добавить **сметану** и свежую зелень." }
]
```

Разделители ставятся где угодно, сколько угодно — или вообще не ставятся.

## Частые ошибки

- **Неправильный slug тега** — тег просто не добавится, ошибки не будет. Проверяй по таблице выше.
- **Запятая после последнего элемента** — JSON не принимает `[...,]`. Последний элемент без запятой.
- **Кириллица** — сохраняй файл в кодировке **UTF-8**. В Блокноте Windows: Файл → Сохранить как → UTF-8.
- **`difficulty`** — только три значения: `easy`, `medium`, `hard`. Всё остальное игнорируется.
